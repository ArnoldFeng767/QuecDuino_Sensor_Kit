# Flame Detection Module

## 1. Module Introduction

The flame detection module is a sensor module used to **detect flames/open flames**. It outputs high/low level signals by receiving infrared light generated by flames, realizing fire alarm and fire source detection.

**Core Parameters**:

- Working voltage: 3.3V–5V
- Output: digital signal (high when no flame / low when flame exists)
- Output: analog signal (high when close / low when far)
- Detection angle: about 60°
- Interface: **MX1.25-2P**
- Application: flame detection, fire alarm, fire source judgment

## 2. Connection Example

Connect the peripheral to the development board one-to-one according to the table and picture instructions:

| Peripheral   | Development Board        |
| ------------ | ------------------------ |
| Flame（+）   | 3.3V                     |
| Flame（-）   | GND                      |

Analog Signal

```python
from misc import ADC
from machine import Pin
import _thread
import utime

def fun():
    while True:
        num=adc.read(adc.ADC0)
        utime.sleep(1)
        print(num)


if __name__=='__main__':
    adc = ADC()
    adc.open()
    _thread.start_new_thread(fun,())
```



Digital Signal

```python
from machine import Pin
import utime

#Configure GPIO as input with pull-down
gpio = Pin(Pin.GPIO31, Pin.IN, Pin.PULL_PD)
gpio1=Pin(Pin.GPIO30,Pin.OUT,Pin.PULL_DISABLE,0)
def main():
    # When the sensor detects a flame, it outputs a high level (1).
    while True:
        if gpio.read() == 0:
            gpio1.write(0)
        else:
            gpio1.write(1)
            print("Flames were detected.")
        utime.sleep_ms(100)
if __name__ == "__main__":
    main()
```
